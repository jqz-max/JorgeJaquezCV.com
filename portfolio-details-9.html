VOX // Cogitator

VOX // Cogitator es una interfaz interactiva inspirada en la estética del Adeptus Mechanicus de Warhammer 40,000. El proyecto utiliza una combinación de HTML, CSS y JavaScript para construir una experiencia visual inspirada en un sistema de procesamiento y consulta.

La interfaz incorpora elementos animados, paneles de información, un núcleo visual central, reloj digital, buscador y diferentes elementos decorativos que simulan un sistema tecnológico y mecánico.

El diseño busca combinar una estética industrial y tecnológica con elementos visuales inspirados en interfaces de ciencia ficción.
